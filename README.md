# ekwing-auto

> 翼课网「同步训练」自动答题工具 —— 填空、选词、填表、选择题、词语听写全自动，朗读类自动跳过。

基于 **Chrome DevTools Protocol** 驱动真实浏览器（Edge / Chrome 均可），不注入脚本、不破解登录，
只是把"人点页面"这件事自动化。全程只用 Python 标准库，无第三方依赖。

## ✨ 特性

- **自动识别题型**：打开任务后读页面模型判定 `fill` / `choice` / `dictation`，不依赖硬编码的题型编号
- **答案来自平台自己的接口**：不猜、不硬编码，选择题选项被打乱也能自适应
- **朗读类自动跳过**：读记词语、读记目标句、课文背诵、课文跟读等需要真人录音的题型不会误点
- **跨浏览器**：Edge / Chrome / Brave / 360 极速等 Chromium 系通用
- **零依赖**：只用 Python 标准库，自带极简 CDP 客户端
- **可只读**：`--dry-run` 只取答案不动页面，`--list` 只看任务清单

## 支持范围

### 浏览器

| 浏览器 | 支持 | 说明 |
|---|---|---|
| Microsoft Edge | ✅ | 已实测 |
| Google Chrome | ✅ | 已实测 |
| Brave / 360 极速 / QQ 浏览器等 Chromium 系 | ✅ | 需支持 `--remote-debugging-port` |
| Firefox | ❌ | 使用 WebDriver BiDi，不是 CDP |

`start-browser.bat` 会自动探测：优先 Edge，其次 Chrome。

### 题型

| 题型 | 判定依据 | 作答方式 |
|---|---|---|
| 词语听写 | 模型里有 `allData[]` | 取 `allData[].text`，逐题键入 |
| 首字母填空 / 适当形式填空 / 选词填空 / 完成表格 | `ansData[qid]` 是数组 | 写入 `ansData` |
| 语法选择 / 阅读理解等选择题 | `ansData[qid]` 是含 `ans` 的对象 | 点选对应 radio |
| 读记词语 / 读记目标句 / 课文背诵 / 课文跟读 | biz `005/008/525/002`，或任务名含"读记 / 背诵 / 跟读 / 朗读 / 口语" | **跳过** |

> 题型判定是运行时做的。遇到结构相同的未登记题型通常也能直接处理；
> 判定失败会明确输出「未识别的题型」而不会乱点。

## 🚀 快速开始

### 1. 环境

- Windows 10/11
- Edge 或 Chrome
- Python 3.9+（`ekw.bat` 会依次尝试：DSH 自带 Python → PATH 里的 `python` → `%LOCALAPPDATA%\Programs\Python\Python3*`）

### 2. 启动可控浏览器

```bat
start-browser.bat            :: 自动选浏览器
start-browser.bat edge       :: 指定 Edge
start-browser.bat chrome 9226 :: 指定 Chrome 与端口
```

会用一个**独立配置目录**（`%LOCALAPPDATA%\ekwing-auto-profile\`）打开浏览器，
**不影响你日常浏览的窗口**。在弹出的窗口里登录翼课网，登录状态会保留。

> 这个窗口要一直开着——工具通过调试端口驱动它。

### 3. 运行

```bat
:: 1) 先看这份作业有哪些任务
ekw.bat --url "https://www.ekwing.com/hw/do?hid=<作业ID>" --list

:: 2) 只取答案，不提交（强烈建议先跑这个）
ekw.bat --url "..." --dry-run

:: 3) 全自动作答并提交
ekw.bat --url "..."

:: 4) 只做指定的几项
ekw.bat --url "..." --only 语法选择,阅读理解
```

`--url` 也可以用 `--hid <作业ID>` 代替。作业 ID 就是作业页 URL 里 `hid=` 后面的数字。

### 命令参考

| 参数 | 说明 |
|---|---|
| `--url` / `--hid` | 作业页面地址或作业 ID |
| `--list` | 只列出任务，不做任何操作 |
| `--dry-run` | 取答案、识别题型，但不作答不提交 |
| `--only a,b` | 只处理指定任务（按任务名匹配） |
| `--inspect <任务名>` | 导出该任务的模型结构与 DOM 特征，开发新题型适配时用 |
| `--port` | 调试端口，默认 `9224` |
| `--param-term` | 取题接口的期号参数，默认 `20260901` |
| `--offline --json-dir <dir>` | 离线解析已下载的题目 JSON，只打印答案 |

## 🔍 工作原理

1. **枚举任务**：作业页把任务渲染进 Avalon 视图模型 `hwCntVm.list`，每项带 `biz / key / ids`。
2. **取题目与答案**：用 `key` 调页面自己的代理接口：

   ```
   POST /proxy
   ------------------------------------------------------------------
   url    = https://acpf.ekwing.com/wapi/getbaseworktimucontent
   method = POST
   data   = {"keys": "<key>", "param_term": "<期号>"}
   ```

   响应的 `question.qus_item[].answer` 就是标准答案，格式 `["[首字母]答案||备选答案"]`。

3. **锁定当前题**：打开任务后对比"打开前后新增的 Avalon 模型"，
   因为旧任务的模型不会被销毁，直接取第一个会串题。

4. **作答**：按模型类型写 `ansData` 或点选 radio，再点「完成 → 确定」，
   由平台自己判分并返回等级。

5. **清理干扰**：每次操作前移除会员推广弹窗与遮罩层，避免点击被拦截。

> 关键点：答案本来就是随题目一起下发到浏览器的（客户端判分），
> 本项目做的是"读取页面状态 + 模拟点击"，并没有攻击服务端。

## ❓ FAQ

**Q：提示"连不上 Chrome 调试端口"？**
先运行 `start-browser.bat`，确认窗口开着；端口被占用时换端口：`start-browser.bat edge 9225` + `--port 9225`。
调试端口有时只绑 `::1`（IPv6）有时只绑 `127.0.0.1`，工具会自动两个都试；也可用环境变量 `CDP_HOST` 指定。

**Q：提示"未登录"？**
在那个被启动的浏览器窗口里登录翼课网即可，登录会保留在独立配置目录里。

**Q：提示"找不到任务卡片"？**
多半是页面结构变了，或弹窗未正常关闭。工具会自动刷新重试一次；仍失败请提 Issue 附页面截图。

**Q：取题为空？**
试试 `--param-term` 指定教材期号（默认 `20260901`）。

**Q：选择题答案每轮不一样？**
平台每次进入任务都会**打乱选项顺序**。工具每轮都从页面模型重新读答案，所以能自适应；
手动核对时不要拿上一轮的字母去套。

**Q：为什么朗读类不做？**
那类题型是语音评测，需要真实录音上传打分，无法通过页面状态"读"出来。
用虚拟麦克风 + TTS 实测会被判 0 分，没有实际意义。

## ⚠️ 已知限制

- 只覆盖有明确答案的客观题；朗读类必须真人完成。
- 页面改版会导致选择器失效（`jsDoWorkCompContainer` / `ansData` / `input[name=choice_*]`）。
- 不伪造作答时长，短时间完成容易被识别。
- 仅在 Windows 上测试过；理论上 macOS/Linux 改掉启动脚本即可。

## 🤝 贡献

欢迎 Issue / PR。**最欢迎的 PR 是新增题型支持**——这个项目就是靠"遇到新题型 → 补一个适配器"长起来的。

完整流程见 **[CONTRIBUTING.md](CONTRIBUTING.md)**，核心三步：

1. `ekw.bat --url "..." --inspect <任务名>` 导出模型结构与 DOM 特征；
2. 在 `JS_TASK_KIND` 里加判定，写一个 `handler(c, vid, items, dry)`；
3. 注册到 `KIND_HANDLERS`，用 `--dry-run` 和实跑各验一次。

提交前请确保不包含任何真实账号、作业 ID、姓名或学校信息，也不要提交 `answers/` 目录。
